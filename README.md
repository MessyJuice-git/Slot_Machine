This project is a simple casino-style game written in C. It demonstrates essential programming concepts such as modular design, functions, loops, random number generation, and user input validation. Players place bets, make guesses, and either win or lose money based on the game logic.

Features:

-Player balance and betting system

-Random number generation using rand()

-Input validation for safe interaction

-Win/loss calculation and game loop

-Option to replay without restarting the program

-Project Structure
